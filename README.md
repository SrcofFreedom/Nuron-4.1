🤖 Nuron 4.1 — Personal AI Assistant

Nuron is a personal AI assistant project developed in Python. It combines voice-assistant-inspired command handling, desktop automation, web search, media controls, and AI-powered responses.

✨ Features

- 🔎 Google and YouTube search
- 🌐 Google Chrome launching
- 🔊 Media and volume controls
- 💻 Desktop application launching
- 📂 Folder access
- 🧮 Calculator and Microsoft Office shortcuts
- 🧠 Gemini API integration for AI-generated responses
- ⚙️ Flask-based HTTP command interface

🛠️ Technologies

- Python
- Flask
- Gemini API
- Windows automation
- HTTP requests and JSON

🔐 Public Version Notice

This repository contains a public-facing version of Nuron 4.1 for educational and portfolio purposes. The server configuration has been modified, and this version is not intended for public deployment as-is.

The project can execute local computer commands when configured and running. Authentication and appropriate access controls should be implemented before exposing the command interface to other devices or networks.

Never publish real API keys, passwords, or private information.

🎯 Project Goal

The goal of Nuron is to explore how Python, AI APIs, and desktop automation can be combined to build a personal digital assistant.

Status: Personal project — under development.
